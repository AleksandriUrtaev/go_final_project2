# Планировщик задач (ToDo Scheduler)

## Описание проекта
Проект представляет собой веб-приложение для планирования задач.  
Позволяет:
- Добавлять задачи с указанием даты, заголовка, комментария и правил повторения;
- Редактировать задачи и отмечать их как выполненные;
- Получать список ближайших задач;
- Выполнять поиск по заголовку, комментариям и дате;
- Аутентифицироваться через пароль с использованием токенов.

Frontend расположен в папке `web`. Сервер написан на Go и использует SQLite в качестве базы данных.

---

## Выполненные задания. Задания повышенной трудности отмечены *
- Создание минимального веб-сервера и отдача статических файлов.
(возможность определять путь к файлу базы данных через переменную окружения.*)
- Инициализация базы данных SQLite с таблицей `scheduler`.
- Реализация функции `NextDate()` для правил повторений задач (`d`, `y`, `w`(*), `m`(*)).
- Обработчики API:
  - `/api/nextdate`
  - `/api/task` (GET, POST, PUT, DELETE)
  - `/api/tasks`
  - `/api/task/done`
- Аутентификация через пароль (`TODO_PASSWORD`) и JWT-токен.(*)
- Поиск задач и фильтрация по дате.(*)
- Dockerfile и запуск контейнера с подключением к локальной БД.

## Локальный запуск

1. Склонируйте репозиторий:
```bash
git clone <репозиторий>
cd <папка проекта>
Установите Go 1.25.1 и зависимости.
Создайте файл .env (по желанию):
TODO_PORT=7540
TODO_DBFILE=./scheduler.db
TODO_PASSWORD=12345
Запуск сервера:
go run main.go
Откройте браузер:
http://localhost:7540
Запуск тестов
В файле tests/settings.go можно задать:
Port = "7540"
DBFile = "../scheduler.db"
Запуск тестов:
go test ./tests
Сборка и запуск через Docker
Сборка образа:
docker build -t scheduler-app .
Запуск контейнера (Git Bash / Linux):
docker run -d -p 7540:7540 \
  -v ${PWD}:/data \
  -e TODO_PASSWORD=12345 \
  -e TODO_DBFILE=/data/scheduler.db \
  --name scheduler-container \
  scheduler-app
Откройте браузер:
http://localhost:7540

Пароль передаётся через переменную окружения при запуске контейнера, чтобы не оставлять его в Dockerfile.
